  • c4dhairattribute — C4D-only node: it has no Houdini counterpart and is skipped when pasting in Houdini.
  • osl / rsosl — aliased to Houdini's `rsosl`; the OSL source travels best-effort, dynamically created ports may not
  • reference — C4D-only node: it has no Houdini counterpart and is skipped when pasting in Houdini.
  • rsramp — node travels, but ramp/curve knot values are not carried in v1 (reset to defaults on paste)
